# 🇺🇦 Ukraine City 3D Simulator & Multiplayer (PR5)

> Інтерактивний 3D симулятор відкритого світу українських міст з повноцінним мультиплеєром, професіями (ЗСУ, Поліція, ДСНС), захистом неба від БПЛА, фізикою водіння автомобілів та танків на **Three.js + React + Vite**.

---

## 🌟 Особливості проекту

### 🏛️ Відкритий світ українських міст
- **Київ 🏛️**: Хрещатик, Майдан Незалежності з монументом Берегині, Золоті Ворота, Поділ, річка Дніпро та Труханів острів.
- **Вінниця 🏙️**: Європейська площа, Вежа Артинова, набережна річки Південний Буг, світломузичний фонтан Roshen.
- **Запоріжжя ⚡**: легендарна гребля ДніпроГЕС, острів Хортиця, 6-смуговий проспект Соборний.

### 🌐 Повноцінний Мультиплеєр (Multiplayer Online)
- **Гібридна P2P архітектура**: WebRTC (`peerjs`) для гри через Інтернет за кодом кімнати + `BroadcastChannel` для гри між вкладками/вікнами браузера.
- **Синхронізація у 3D**: автомобілі, танки, пішоходи з різними скінами та зброєю у руках.
- **3D Nameplate & Чат**: відображення нікнейму, HP, спливаючих мовних хмаринок (Speech Bubbles), швидкі фрази на клавішу `[T]`, таблиця гравців онлайн на `[TAB]`.

### 🪖 Професія ЗСУ, ППО та Захист Неба
- **Повітряна тривога**: процедурна сирена, наліт ударних БПЛА «Шахед-136». Якщо не збити дрон, він пікірує у будівлі міста з потужним вибухом.
- **Арсенал ППО**:
  - `[8]` — Автомат АК-74 5.45мм для стрільби чергами.
  - `[9]` — ПЗРК «Stinger» / «Ігла» з керованою ракетою.
  - `[0]` — FPV-дрон Камікадзе з видом від першої особи (FPV OSD).
- **Важка бронетехніка (Тільки для Армії)**:
  - Основний бойовий танк **Т-64БВ** (125мм гармата, постріл на `[Space]`/`[Q]`).
  - Бронеавтомобіль **«Козак-2М»** із зенітною туреллю.

### 🚓 Поліція 102, ДСНС 101 та Міська Інфраструктура
- **Поліція**: патрульне авто з мигалками та сиреною `[G]`, затримання правопорушників, тайзер, кийок, кайданки.
- **Смартфон `[P]`**: виклики екстрених служб (101 ДСНС, 102 Поліція), ситуаційний центр ППО, смс жителям міста.
- **Житло та магазини**: купівля квартир та будинків, супермаркети «АТБ» та «Сільпо», збройовий магазин «Калібр».
- **Керування авто**: детальна фізика, дрифт на ручнику `[Space]`, вибір ліміту швидкості (100, 200, 300 км/год, MAX), автопілот FSD, салон автомобіля.
- **Повноекранний режим**: клавіша `[C]`.

| Дія | Клавіша |

| **Рух авто / пішохода** | `W`, `A`, `S`, `D` або стрілки |

## 🛠️ Встановлення та запуск

Вимоги: встановлений [Node.js](https://nodejs.org/) (версія 18 або новіша).

1. Клонувати репозиторій:
```bash
git clone https://github.com/<ваш-логін>/<назва-репозиторію>.git
cd <назва-репозиторію>
```

2. Встановити залежності:
```bash
npm install
```

3. Запустити локальний сервер розробки:
```bash
npm run dev
```
Відкрийте посилання `http://localhost:5173/` у вашому браузері.

4. Зібрати для продакшну:
```bash
npm run build
```
